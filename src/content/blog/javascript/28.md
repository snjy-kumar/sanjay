What it is
</h2>
<p>An upload in a personal project sent every text field and dropped the file. I had built the body by hand as JSON. A <code>File</code> does not become the bytes of the file inside <code>JSON.stringify</code>. It becomes <code>{}</code> or a stub, and the server never sees a multipart part. The text fields working made the bug look like a server problem.</p>
<p><code>FormData</code> is the encoding <code>multipart/form-data</code> already expects. Construct it from the form element and it picks up named controls, including file inputs. <code>append</code> adds a field that is not a control. Pass the object as <code>fetch</code>’s <code>body</code>.</p>
<p>Do not set <code>Content-Type</code> yourself for that body. The browser must add the multipart boundary. If I set <code>multipart/form-data</code> without the boundary, the server cannot split the parts. If I set <code>application/json</code>, I have contradicted the body. Leaving the header unset lets <code>fetch</code> set the right one.</p>
<p>I use the form as the source of names. A hand-built list of fields drifts the moment the markup gains an input. <code>FormData</code> reads what the person actually submitted.</p>
</section>

New
</h2>
<p><strong>Right approach: new FormData(form) as the fetch body, with no manual multipart content type</strong></p>
<p><strong>Best case.</strong> Named controls and the file travel as parts. Extra values go through <code>append</code>. The browser writes the boundary.</p>
<p><strong>Worst case.</strong> A disabled field or a control outside the form silently missing. I check the form’s controls, not a parallel object I built from memory.</p>
<p>After: the body is the form, plus one explicit extra field.</p>

When to use which
</h2>
<p>Use <code>FormData</code> for forms that include files or that already express their fields as controls. Use JSON when the endpoint wants JSON and there is no file. Never set <code>Content-Type</code> on a <code>FormData</code> body. Read files from the form rather than copying them into an object first.</p>
<div class="when">
<div class="when-row"><span>Text plus a file input</span><span class="when-choice">FormData</span></div>
<div class="when-row"><span>A JSON API and no file</span><span class="when-choice">JSON.stringify</span></div>
<div class="when-row"><span>An extra flag alongside the form</span><span class="when-choice">body.append</span></div>
<div class="when-row"><span>You want to set the multipart header yourself</span><span class="when-choice">let the browser do it</span></div>
</div>
</section>
