What it is
</h2>
<p>This note closes the JavaScript series. Thirty notes came before it, one habit each: scope, equality, nullish values, <code>typeof null</code>, coercion at the edge, hoisting as three different rules, closures, the array method that matches the job, <code>Map</code> for real dictionaries, and <code>JSON.parse</code> that checks shape.</p>
<p>The second half is the browser. <code>this</code> is the call. Methods live on the prototype. <code>await</code> still needs <code>try</code>. <code>Promise.all</code> and <code>Promise.allSettled</code> are product choices. Microtasks run before timers. Debounce limits frequency and abort limits stale work. Modules have a boundary. Defaults and <code>?.</code> are policies, not blankets. <code>structuredClone</code> is not JSON. Text is <code>textContent</code>. Delegation, <code>preventDefault</code>, layout order, observers, storage, <code>FormData</code>, and <code>URLSearchParams</code> are all the platform doing a job I should not reimplement badly.</p>
<p>The through-line is smaller than the list. I name the rule the language actually has. I convert and validate at the edge. I give failure a branch a person can read. I do not hide a quirk with a shorter expression if the shorter expression changes the meaning.</p>
<p>An older snippet in a personal repo can still concatenate a query or parse storage with no <code>catch</code>. The close is that each of those bugs has a note. I fix the one the next click will hit.</p>
</section>

New

<p><strong>Right approach: one explicit rule per boundary: shape, number, equality, and encoding</strong></p>

When to use which
</h2>
<p>I reopen the note that names the bug. A leaked <code>var</code> sends me to scope. A zero that vanished sends me to truthiness and <code>??</code>. A thrown <code>JSON.parse</code> sends me to the parse note. A wrong URL sends me to <code>URLSearchParams</code>. A click that survived sends me to <code>preventDefault</code> or delegation. The habit is to match the failure, not to collect APIs.</p>
<div class="when">
<div class="when-row"><span>A value changed type at the edge</span><span class="when-choice">convert and validate there</span></div>
<div class="when-row"><span>A shortcut hid zero, null, or empty</span><span class="when-choice">name the comparison</span></div>
<div class="when-row"><span>The browser already has the API</span><span class="when-choice">use it instead of a string or a scroll loop</span></div>
<div class="when-row"><span>The UI can fail</span><span class="when-choice">show that branch</span></div>
</div>
