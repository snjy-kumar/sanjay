What it is
</h2>
<p>This note closes the React series. The pages before it are the habits I kept: derive what is a pure function, put gestures in handlers, key rows with a stable id, keep state local until a second reader exists, and decide whether an input is controlled.</p>
<p>The rest of the series is the same care for lifetime and for honesty. Callbacks remember their render, so I update from the previous state or list the dependency. Hooks run in one order. I memoize a cost I can name. Context is a broadcast, not a way to avoid three props. Forms stay explicit. Components stay small until a third real use. Requests that do not depend on each other start together, and they abort when the screen leaves. State paints. Refs remember.</p>
<p>The scheduled title of this close mentions a card set. What I published is one long note per habit, then this page. I am not adding imaginary extras to match a round number.</p>
<p>An older component in a personal repo can still be a blank <code>map</code> over a fetch. The close is that I know which branch to add first, and I can point at the note that shows it.</p>
</section>

When to use which
