What it is
</h2>
<p>I lifted state to the top of the tree the moment two components might need it someday. The app looked architected. Every keystroke in a filter re-rendered the editor, the preview, and anything else <code>App</code> returned. Pulling that state back down later was the painful direction.</p>
<p>State wants to live where it is used. A search string that only the list reads can live in the list’s parent, next to the list, not in the root. I lift when a second, real component needs the same value now: a list and a map that must share one selection, two siblings that edit one draft.</p>
<p>When I do lift, I lift the smallest piece. The shared query goes up. The unrelated editor draft stays put. Lifting a whole form blob because one field is shared makes every field global.</p>
<p>Premature lifting is how a local filter becomes global traffic. I can always lift later, in one move, when the second reader exists.</p>
</section>

<section class="section" id="when">
<h2>
<svg class="ico" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true" fill="none" stroke="#111" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round"><path d="M3.6 2.4v9.2"/><path d="M3.6 6.4h4.35"/><path d="M7.95 6.4 11.15 3.5"/><path d="M7.95 6.4 11.15 9.3"/></svg>
When to use which
</h2>
<p>Leave state in the component that renders it until a sibling must read or change the same value. Then lift that value to their closest shared parent. Do not lift a whole form to share one field. Do not introduce context just because a prop passed through one intermediate component.</p>
<div class="when">
<div class="when-row"><span>Only one subtree reads it</span><span class="when-choice">keep it local</span></div>
<div class="when-row"><span>Two siblings need the same value now</span><span class="when-choice">lift that value</span></div>
<div class="when-row"><span>One field of a form is shared</span><span class="when-choice">lift that field</span></div>
<div class="when-row"><span>A prop passes through a single child</span><span class="when-choice">passing props is fine</span></div>
</div>
