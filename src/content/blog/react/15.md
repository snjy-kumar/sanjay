What it is
</h2>
<p>When junior and mid-level engineers build portfolio projects, they often try to demonstrate competence by stacking dependencies: Redux Toolkit for thirty lines of state, a complex animation suite, three external modal libraries, and six layers of wrapper components.</p>
<p>When an experienced engineer reviews that code, they don’t see sophistication; they see accidental complexity. They see components that break when you press the Tab key, forms that lose focus when re-rendering, unhandled error states, and <code>useEffect</code> hooks used to synchronize values that could have been derived in two lines of math.</p>
<p>Honest React is understated. It solves real browser constraints: it uses native semantic elements (<code>&lt;dialog&gt;</code>, <code>&lt;button&gt;</code>, <code>&lt;form&gt;</code>), provides accessible labels for screen readers, handles network failure with a working retry button, derives state during render, and exposes clean, composable prop boundaries.</p>
<p>A senior engineer will choose a developer who writes fifty lines of clear, robust, accessible code over one who imports five megabytes of third-party abstractions to build a simple todo list.</p>
</section>

When to use which
</h2>
<p>Signal honest engineering competence: write semantic HTML first, derive values during render, and handle failure gracefully.</p>
<div class="when">
<div class="when-row"><span>Filtering or sorting data</span><span class="when-choice">derive in render (no useEffect)</span></div>
<div class="when-row"><span>Interactive actions</span><span class="when-choice">&lt;button&gt; (never &lt;div onClick&gt;)</span></div>
<div class="when-row"><span>Empty list state</span><span class="when-choice">explicit copy (not blank screen)</span></div>
<div class="when-row"><span>Component styling</span><span class="when-choice">clean CSS with real focus outlines</span></div>
</div>
