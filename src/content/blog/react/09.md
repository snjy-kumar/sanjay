What it is
</h2>
<p>I created a context the moment a prop passed through three components. Then a tiny query update re-rendered every consumer of a mega value that also held the session, the theme, and the draft. Finding who subscribed was harder than reading a prop.</p>
<p>Context is a broadcast. A prop is a cable. Cables are a good design for a short distance: the data flow is visible, the component is easy to test, and nothing else re-renders. I pass props through one or two intermediates without guilt.</p>
<p>I use context for a value that many distant readers share: theme, locale, the signed-in session. I split contexts so a frequently changing value does not sit beside a stable one. A provider value that is a fresh object every render (<code>value={{ session, query }}</code>) will notify consumers every time, even when <code>session</code> did not change.</p>
<p>If only one branch needs the value, I pass it. I save the radio tower for a real audience.</p>

<h2>
<svg class="ico" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true" fill="none" stroke="#111" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round"><path d="M3.6 2.4v9.2"/><path d="M3.6 6.4h4.35"/><path d="M7.95 6.4 11.15 3.5"/><path d="M7.95 6.4 11.15 9.3"/></svg>
When to use which
</h2>
<p>Pass a prop when you can see the destination from the source. Use context when many components, far apart, must read the same value. Split a fast-changing value from a slow one. Memoize a context value only when you have seen consumers re-render on an unchanged piece of it.</p>
<div class="when">
<div class="when-row"><span>One or two components nearby</span><span class="when-choice">props</span></div>
<div class="when-row"><span>Session, theme, or locale</span><span class="when-choice">context</span></div>
<div class="when-row"><span>A value that changes every keystroke</span><span class="when-choice">local state or a separate context</span></div>
<div class="when-row"><span>A new object as value every render</span><span class="when-choice">stabilize or split</span></div>
</div>
</section>
