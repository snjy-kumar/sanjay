What it is
</h2>
<p>I used to store <code>fullName</code> in state next to <code>firstName</code> and <code>lastName</code>. The header on a personal project showed an old name after I edited the form. I had updated two pieces of state and forgotten the third. The bug was not mysterious. Two copies of one fact had been allowed to disagree.</p>
<p>If a value is a pure function of state or props I already have, I compute it while rendering. <code>fullName</code> is <code>first</code> and <code>last</code> joined and trimmed, on every render, so it cannot go stale. There is no <code>setFullName</code> to forget.</p>
<p>The exception is an editable override: a display name the person can type separately from the given names. That override is real state, because it is not a pure function anymore. Expensive derivations are a different question. I measure them before I wrap them, and I still do not store a second copy “just in case.”</p>
<p>A form that keeps both the source fields and a cached label will eventually ship a screen where the heading and the inputs tell two stories. I keep one story.</p>
</section>

<section class="section" id="when">
<h2>
<svg class="ico" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true" fill="none" stroke="#111" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round"><path d="M3.6 2.4v9.2"/><path d="M3.6 6.4h4.35"/><path d="M7.95 6.4 11.15 3.5"/><path d="M7.95 6.4 11.15 9.3"/></svg>
When to use which
</h2>
<p>Store the smallest source facts the user can change. Derive labels, counts, filters, and validity when they are calculated from those facts. Store a second field only when the user can edit it independently, or when you are deliberately snapshotting a value that must not track the source.</p>
<div class="when">
<div class="when-row"><span>A label computed from other fields</span><span class="when-choice">derive during render</span></div>
<div class="when-row"><span>A value the user edits on its own</span><span class="when-choice">state</span></div>
<div class="when-row"><span>A filter over a list you already hold</span><span class="when-choice">derive</span></div>
<div class="when-row"><span>A snapshot that must ignore later edits</span><span class="when-choice">state, copied on purpose</span></div>
</div>
</section>
