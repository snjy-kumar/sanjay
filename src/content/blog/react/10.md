What it is
</h2>
<p>My early personal apps had two UIs: the happy path, and a blank screen. Loading looked like a bug. Errors lived in the console. An empty list looked identical to a request that had not finished.</p>
<p>I model the request as states that cannot be confused: idle, loading, error with a message, and success with items. Empty is a success with no rows, and the copy says that. It does not say “something broke,” and it does not look like a spinner that stalled.</p>
<p>The error state has a retry that calls the same loader. I do not only <code>console.error</code>. A person using the demo cannot open my console, and neither can I when I click through it a week later.</p>
<p>A component that only looks right with perfect data is not done. The in-between states are part of the design, written in the same function, in the HTML the first render returns.</p>

New
</h2>
<p><strong>Right approach: branch on loading, error, empty, and then the list</strong></p>
<p><strong>Best case.</strong> Each state has its own sentence. Retry calls the loader again. Empty and loading cannot share one blank node.</p>
<p><strong>Worst case.</strong> A boolean pile, <code>isLoading</code> and <code>error</code> and <code>items</code>, that allows loading and error at once. A single status union keeps those combinations unrepresentable.</p>
<p>After: the list renders only in the success branch that actually has rows.</p>

<h2>
<svg class="ico" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true" fill="none" stroke="#111" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round"><path d="M3.6 2.4v9.2"/><path d="M3.6 6.4h4.35"/><path d="M7.95 6.4 11.15 3.5"/><path d="M7.95 6.4 11.15 9.3"/></svg>
When to use which
</h2>
<p>Give every request a status the UI can name. Treat an empty success differently from loading and from failure. Put retry in the error branch. If two booleans can both be true, replace them with one union.</p>
<div class="when">
<div class="when-row"><span>Request in flight</span><span class="when-choice">loading copy</span></div>
<div class="when-row"><span>Request failed</span><span class="when-choice">error and a retry</span></div>
<div class="when-row"><span>Success with zero rows</span><span class="when-choice">empty copy</span></div>
<div class="when-row"><span>Success with rows</span><span class="when-choice">the list</span></div>
</div>
