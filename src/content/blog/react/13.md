<h2>

What it is
</h2>
<p>When fetching data directly inside an effect, the network is asynchronous, but components are ephemeral. If a user clicks between two tabs—say, from “TypeScript” to “React”—two fetch requests are sent over the wire.</p>
<p>If the slower request finishes second, it calls <code>setState</code> with outdated data. The screen displays the contents of the tab the user left two seconds ago. This is a classic race condition, and it happens silently without throwing a console error.</p>
<p>Another common bug is unmounting: when the user navigates away before a request completes, the response handler tries to update state on a dead component. React warns about memory leaks, but the deeper problem is unmanaged async lifecycle.</p>
<p>The web standard solution is <code>AbortController</code>. By passing <code>controller.signal</code> to the <code>fetch</code> call and aborting in the effect’s cleanup function, any in-flight request is immediately cancelled when dependencies change or the component unmounts.</p>
</section>

New
</h2>
<p><strong>Right approach: abort stale network requests or ignore resolved flags</strong></p>
<p><strong>Best case.</strong> Stale requests are immediately cancelled at the network level, conserving user bandwidth and preventing race conditions completely.</p>
<p><strong>Worst case.</strong> If the browser does not support fetch abortion (rare), a simple <code>let active = true</code> boolean flag ignored in the then-callback accomplishes the same safety.</p>
<p>After: explicit cleanup function aborts prior requests.</p>

<h2>
<svg class="ico" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true" fill="none" stroke="#111" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round"><path d="M3.6 2.4v9.2"/><path d="M3.6 6.4h4.35"/><path d="M7.95 6.4 11.15 3.5"/><path d="M7.95 6.4 11.15 9.3"/></svg>
When to use which
</h2>
<p>Whenever an effect initiates an asynchronous operation—whether a fetch, timer, or socket subscription—always provide an explicit cleanup function.</p>
<div class="when">
<div class="when-row"><span>Native fetch requests</span><span class="when-choice">AbortController signal</span></div>
<div class="when-row"><span>Custom Promise client</span><span class="when-choice">ignore = true flag</span></div>
<div class="when-row"><span>Event listeners / WebSockets</span><span class="when-choice">removeEventListener / close()</span></div>
<div class="when-row"><span>setInterval / setTimeout</span><span class="when-choice">clearInterval / clearTimeout</span></div>
</div>
</section>
