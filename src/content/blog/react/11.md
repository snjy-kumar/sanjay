What it is
</h2>
<p>When a form grows past three inputs, the easiest thing to reach for is a single state object: <code>const [form, setForm] = useState(&#123; name: &quot;&quot;, email: &quot;&quot;, bio: &quot;&quot;, ... &#125;)</code> with a generic <code>onChange</code> handler spreading the previous draft.</p>
<p>It looks clean until someone types into the bio field. Every keystroke updates the parent state, re-renders twelve other inputs, recalibrates error states for untouched fields, and creates noticeable input latency on slower devices. If a child input happens to be wrapped in an inline component, it loses focus on the second character.</p>
<p>Forms are one of the few places in web development where the browser’s built-in state machine is already exceptional. The DOM already knows what characters are inside an input. Unless an input needs live validation or conditional UI based on its exact text, it does not need to sit in React state on every single keystroke.</p>
<p>For submitting data, <code>new FormData(event.currentTarget)</code> extracts clean values in one shot on submit. When live state is genuinely needed, isolate that specific field or branch to its own component boundary so typing in one box does not shake the whole tree.</p>
</section>

New

<p><strong>Right approach: read values on submission or isolate live fields</strong></p>

When to use which
</h2>
<p>Only synchronize input characters into React state when other components actively depend on that value right now. Otherwise, let the browser manage input drafts.</p>
<div class="when">
<div class="when-row"><span>Standard submit forms</span><span class="when-choice">uncontrolled with FormData</span></div>
<div class="when-row"><span>Live search / autocomplete</span><span class="when-choice">local controlled state in search bar</span></div>
<div class="when-row"><span>Character limit counter</span><span class="when-choice">isolated local input component</span></div>
<div class="when-row"><span>Multi-step wizard draft</span><span class="when-choice">commit step data on "Next"</span></div>
</div>
</section>
