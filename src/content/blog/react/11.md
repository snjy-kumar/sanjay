What it is
</h2>
<p>I stored an entire form as one object and spread a new copy on every field: <code>setForm({ ...form, email: value })</code>. It worked until validation, dirty tracking, and a nested address showed up. A typo in a key added a property and left the real one untouched. The input looked frozen because it was still reading <code>form.email</code>.</p>
<p>The spread has a second bug. If two updates in the same tick both copy <code>form</code> from the render, the second replace wins and the first field is dropped. The functional update <code>setForm((prev) =&gt; ({ ...prev, email: value }))</code> fixes the race. It does not fix the typo. An excess key is still a silent extra property if the state type is a wide record.</p>
<p>On small forms I now use one <code>useState</code> per field. <code>setEmail</code> cannot invent <code>emial</code>. Derived bits, such as “can submit,” are computed, not stored in the blob. When the fields share a transition, a reducer with a typed action union makes illegal keys unrepresentable.</p>
<p>A form is a set of fields with rules. If updating one input requires me to remember the whole object, the state is bigger than the edit.</p>
</section>

New

<p><strong>Right approach: a state cell per field, or a reducer whose actions name the fields</strong></p>

When to use which
</h2>
<p>Use separate state for a handful of fields. Use a typed reducer when many fields update together or several events share transition rules. Use a functional spread only if you truly want one object, and never build the next object from a <code>form</code> variable closed over from render when another update might be queued.</p>
<div class="when">
<div class="when-row"><span>A few independent inputs</span><span class="when-choice">one useState each</span></div>
<div class="when-row"><span>Many fields with shared rules</span><span class="when-choice">typed reducer</span></div>
<div class="when-row"><span>A value computed from the fields</span><span class="when-choice">derive it</span></div>
<div class="when-row"><span>A spread of a closed-over object</span><span class="when-choice">functional update, or split it</span></div>
</div>
