What it is
</h2>
<p>I wrapped every callback in <code>useCallback</code> and every string in <code>useMemo</code> because a post called it best practice. The code got louder. I could not point at a render that got cheaper. Sometimes it got worse: memoization allocates a cache and compares dependencies, which is its own work.</p>
<p>I memoize when I can name the reason. A child is wrapped in <code>memo</code> and would otherwise re-render because its callback identity changes. A value is a dependency of another hook and a new object every render retriggers that hook. Or I have seen real jank, usually a sort or a filter over a large list, and the inputs change less often than the parent renders.</p>
<p>A label like a count concatenated with a word is not that case. Computing it is cheaper than remembering it. A click handler passed to a native <code>&lt;button&gt;</code> does not need <code>useCallback</code> unless a memoized child receives it.</p>
<p>Dependencies are a second program. A wrong array is a stale bug wearing an optimization costume. If I cannot name the re-render I am preventing, I delete the wrapper and keep the plain value.</p>
</section>

When to use which
</h2>
<p>Start without <code>useMemo</code> and <code>useCallback</code>. Add <code>useCallback</code> when a <code>memo</code> child or an effect depends on that function’s identity. Add <code>useMemo</code> when a calculation is actually expensive or produces an object that would retrigger a hook. Recheck the dependency array in the same edit.</p>
<div class="when">
<div class="when-row"><span>A string, boolean, or cheap calculation</span><span class="when-choice">plain expression</span></div>
<div class="when-row"><span>A memoized child receives a function</span><span class="when-choice">useCallback</span></div>
<div class="when-row"><span>A large sort or filter you measured</span><span class="when-choice">useMemo</span></div>
<div class="when-row"><span>A new object used as an effect dependency</span><span class="when-choice">useMemo or move it inside</span></div>
</div>
</section>
