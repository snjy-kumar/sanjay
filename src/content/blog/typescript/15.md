What it is
</h2>
<p>When I open my own repositories now, I do not ask whether a file is <code>.ts</code>. I ask whether the types are honest. A project can run the compiler and still be JavaScript with annotations: <code>string</code> for a lifecycle, <code>any</code> on the model, <code>as User</code> on every response.</p>
<p>Honest, in the notes so far, means a few concrete habits. Closed sets are unions. Empty is modeled on purpose. Functions that cross a file have real parameter and return types. <code>unknown</code> stops at a parser. UI state that cannot overlap is a discriminated union. Shared helpers use a small generic instead of <code>any</code>.</p>
<p>Someone skimming a demo may only see the screen. The next person who reads the diff sees the standard: a bug at the boundary fails in the parser, a typo in a flag fails <code>satisfies</code>, a forgotten status fails a <code>never</code> check. That is the signal I want a portfolio to send. I am still tightening older projects. The point of publishing the work is to show the standard, not a frozen demo.</p>
<p>I do not add types for ceremony. A local const can be inferred. A public helper I will call from two screens gets a signature. Judgment is which lie I remove next, in a small diff.</p>
</section>

<p><strong>Right approach: a parser at the boundary and ordinary types after it</strong></p>

<p><strong>Worst case.</strong> A theatrical type for a value that should have been inferred, or a parser so large I stop maintaining it. Honest means accurate, not maximal.</p>

<section class="section" id="when">
<h2>
<svg class="ico" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true" fill="none" stroke="#111" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round"><path d="M3.6 2.4v9.2"/><path d="M3.6 6.4h4.35"/><path d="M7.95 6.4 11.15 3.5"/><path d="M7.95 6.4 11.15 9.3"/></svg>
When to use which
</h2>
<p>Infer types for locals. Annotate signatures I reuse. Parse at boundaries. Use unions for closed sets and for state that should not overlap. Keep <code>any</code> out of models. When I review a repo, I look for one dishonest type and remove it. A small diff is a clearer signal than a rewrite.</p>
<div class="when">
<div class="when-row"><span>A local value with an obvious shape</span><span class="when-choice">infer it</span></div>
<div class="when-row"><span>A helper used in more than one file</span><span class="when-choice">annotate the signature</span></div>
<div class="when-row"><span>JSON or storage</span><span class="when-choice">unknown, then parse</span></div>
<div class="when-row"><span>A lifecycle or fetch state</span><span class="when-choice">a union, not string</span></div>
</div>
</section>
