What it is
</h2>
<p>I kept three versions of the same user model in a personal project: the record, the edit form, and the preview card. They started identical. Then I renamed <code>email</code> to <code>contactEmail</code> on the record and missed the form. The form still compiled. It wrote the old key.</p>
<p><code>Pick&lt;User, &quot;id&quot; | &quot;name&quot;&gt;</code> builds a type from a subset of keys. <code>Omit&lt;User, &quot;email&quot;&gt;</code> builds the complement. <code>Partial&lt;T&gt;</code> makes every field optional, which is what an update payload often is. Stack them when only some fields may be patched: <code>Partial&lt;Pick&lt;User, &quot;name&quot; | &quot;email&quot;&gt;&gt;</code>.</p>
<p>These utilities are aliases over one source. They do not validate JSON, and they do not make a field optional at runtime. A <code>Partial&lt;User&gt;</code> value can still be <code>{}</code>. If the form requires a name, <code>Partial</code> is the wrong tool and a dedicated type with <code>name: string</code> is the honest one.</p>
<p>The win is drift. Change <code>email</code>’s type on <code>User</code> and every <code>Pick</code> / <code>Omit</code> / <code>Partial</code> that mentions it updates. I still read the derived type once to be sure I did not omit a field the screen needs.</p>
</section>

<h2>

When to use which
</h2>
<p>Keep a hand-written type when the shape is not a slice of an existing model. Use <code>Pick</code> for a card or a list row, <code>Omit</code> when one sensitive field must not be copied into a view model, and <code>Partial</code> only for fields the product allows to be absent. Combine <code>Partial</code> and <code>Pick</code> when an update may include some of a known subset and must not include the rest.</p>
<div class="when">
<div class="when-row"><span>A shape that is not a slice</span><span class="when-choice">write the type</span></div>
<div class="when-row"><span>A card that shows two fields</span><span class="when-choice">Pick</span></div>
<div class="when-row"><span>A view that drops one field</span><span class="when-choice">Omit</span></div>
<div class="when-row"><span>A patch of some editable fields</span><span class="when-choice">Partial of a Pick</span></div>
</div>
